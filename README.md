# StepSense
Open index.html in Chrome or Edge (best: `python -m http.server`, then http://localhost:8000 so the microphone permission sticks). Tap once to start audio.
Quick tour: connect footwear, Start walking (obstacles appear on their own with panned beeps), "navigate to library", emergency -> confirm/cancel, Caregiver tab.
Note: sensors, Bluetooth, GPS and SOS delivery are not wired to real hardware or services in this build.
